# 现场接入前的信息清单

这份清单在 M4/M6 之前填写。当前没有现场数据，所有未采集项目保持 UNKNOWN，阻塞依赖它的能力。这些未知不是允许 Codex 猜测的参数。

| 项目 | 需要取得的证据 | 缺失时处理 |
|---|---|---|
| 商品型号与 SDK 家族 | 铭牌、厂商说明或售后确认；区分商品名称和 ZSL/MaxPro 协议家族 | 不选择默认 SDK |
| 点足/轮足及当前模式 | 实物与厂商模式说明 | 不推断速度/低层能力 |
| 本体/运控/SDK 版本 | 实机只读版本输出与对应 SDK 文件 | 固件兼容 UNKNOWN |
| 执行主机 | OS、CPU、内存、可用磁盘、是否原厂计算单元 | 不决定镜像架构 |
| SDK 工件 | 来自厂商的文件、架构、实际哈希、使用条件 | 不下载来历不明二进制 |
| 网络拓扑 | 本体 IP、主机 IP、接口、路由、双网卡/上网方式 | 只读检查，不自动改网卡 |
| 机器人侧配置 | 原始文件、权限、现有启动方式与恢复方式 | 不覆盖、不重启 |
| 传感器 | 实际型号、驱动、固件、点云/IMU字段、是否直连主机 | 不启用相应 SLAM Profile |
| 时间与外参 | 数据时钟来源、偏差、传感器安装变换 | 不假造 TF 或同步参数 |
| 高层状态语义 | 单位、坐标系、返回码、当前控制源、位置重置行为 | 不发布为合格 /odom |
| 停止与抢占 | 厂商手册、物理遥控/停止途径、控制权说明 | 运动功能保持禁用 |
| 失联机制 | 本体在断线/主机断电后的行为及现场验证 | 禁止声称断连安全 |
| 可用测试区域 | 现场人员、平整空旷区域、设备许可与围护 | 只允许软件/只读验证 |

不得把密码、私钥或完整敏感配置上传到公开 GitHub。凭据由现场人员在受控交互中输入；报告默认去敏。序列号对外展示应遮盖。
