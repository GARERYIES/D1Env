# M3 交付证据索引

本目录保存本轮实际运行输出的 51 份选定副本，包含最终测试、TDD RED/GREEN、真实 Docker/ROS、便携包来源/搬迁和独立工件审查。截图位于 `reports/screenshots/`；完整范围与命令见 `reports/M3-summary.md`，独立结论见 `reports/M3-review.md`。

`INDEX.json` 对每份证据分别记录原始私有文件路径、大小、SHA-256，以及交付副本路径、大小、SHA-256。来源锁仍引用原始 evidence hash；去敏副本不冒充原始字节。19 份副本做了去敏、32 份保持原字节。副本包含失败输出，文件存在或探针脚本退出 0 不代表被测业务成功；请按报告里的产品退出码、断言和范围判断。

去敏处理覆盖凭据字段/文本赋值、本机个人/临时路径和 IP 标识。raw logs、私有会话引导、数据库、浏览器认证文件与镜像层不在本目录。第三方公开来源/许可证材料不因广谱匹配而被删除；runtime/ROS 归档另有实际清单核对与已分类的独立扫描记录。

最终 Python 两个版本各 297 PASS 是同一套件；104 项 Docker/ROS 用例是其子集，独立审查 297 PASS 是复核。29 项界面单元与 2 项真实浏览器 E2E 分列；真实 Docker 操作另列，不累加成 pytest 用例。NOT_RUN/blocked 见阶段报告，不能计为通过。
